# Stock Farsi

App Android de suivi du stock et des péremptions — Pharmacie Farsi, Zéralda.

- `data/stock.json` : le stock partagé (modifié par l'app).
- L'APK est fabriqué automatiquement par GitHub Actions : onglet **Releases** → `StockFarsi.apk`.
- Secret `STOCK_TOKEN` : clé d'accès intégrée à l'app (sinon, à saisir dans ⚙ Réglages).
